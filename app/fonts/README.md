# Local fonts

- **`VintageGoods.ttf`** — loaded in `app/layout.tsx` as **Vintage Goods** (`font-arse-smart` / `--font-vintage-goods`). Required for the smart A.R.S.E wordmark.
- If you only keep one file, **TTF is used by the app**; you can remove the duplicate `.otf` or change `src` in `layout.tsx` to `./fonts/VintageGoods.otf`.
